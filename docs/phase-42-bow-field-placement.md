# 第四十二阶段：基础长弓的场上恢复

2026-10-15，v0.43.0。继续“小关重开＋受限玩家恢复”。本阶段允许一张基础长弓保留在玩家场上，不再要求先将它移回手牌。重编程和敌人精确恢复继续搁置。

## 支持范围

新 FIELD 格式 F12 沿用 Q2 的技能资格契约，绑定实际布局 checksum。仅接受 D/H/T/F 合计一张未升级长弓，且它位于 FIELD：攻击、基础／当前生命均为1，等级1，无属性修正，generic计数0，无特殊计数，turnActive=True。技能仍须完整匹配已审阅定义、单个效果、flags=[0]，used只能为0或1。可与已支持的普通果实场地卡共存。

有长弓的场地才选择 F12；普通果实场地仍保存为 F11。旧格式、checksum、Q1/Q2含义及普通果实准入规则不变。多张长弓、升级长弓、跨区长弓副本、其他新技能历史均未开放。角色充能 C3 独立验证，本轮场地案例覆盖 False、未满充来源，不能据此宣称其他角色能力状态已恢复。

## 恢复过程与失败处理

沿用既有手牌暂存、原生出牌及短暂技能列表抑制流程。新增长弓守卫在抑制前记录完整对象身份，并在 count=0 时只读核对原数组中的一个已绑定效果；允许的变化只有 HAND→FIELD。核对范围包括世界／引擎／卡牌的 weak identity、原生对象及共享控制块、数组指针与容量、效果对象／控制块／GUID／owner、完整 CardInfo、flags 原始存储和 newborn used=0。数组头未变但效果条目被原地替换也会拒绝。

恢复列表数量后再次验证普通观测，全部布局、数值和抑制解除完成后，才进入既有 ONCE 回放。未用来源不写；已用来源只执行一次受守卫的 native true 调用。不新增 flags 写入、setter(false)、效果重建或重新尝试。

独立复核发现并修正两处问题：普通日志会截断完整身份记录；严格日志写入失败又可能阻止身份仍有效的列表解除抑制。最终使用专用有界完整日志，将证据失败与身份失败分别锁存。证据失败永久阻止资格成功，但终结清理可在重新验证完整原身份后解除抑制；身份失败始终禁写。清理不会清除失败状态或重新开启精确恢复。日志 I/O 故障和身份漂移分支经过源码复核，未声称做过实机故障注入。

四个完整记录分别覆盖抑制前、抑制后、数量恢复前、恢复后，数量为1/0/0/1，位置为0/0/3/3；最终 F1 独立绑定同一原生卡牌和效果身份。中间记录是运行时断言，不等于独立瞬时快照、连续队列观测或完整 UI 注册证明。
