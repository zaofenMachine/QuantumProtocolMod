## 准入与兼容

F13 要求 D/H/T/F 合计恰两张未升级 `sakuraBow@0`，两张均在 PLAYER FIELD、槽位不同。每张必须攻击与基础／当前生命均为1、等级1、无属性修正、generic计数0、无特殊计数、turnActive=True；技能是已审阅的单个基础效果，flags=[0]，used只接受0或1。可与既有准入的普通果实场地卡共存。其他卡牌仍受既有区域、身份与特殊卡守卫约束。

F12 保留“恰一张基础长弓且位于FIELD”的原义，普通果实场地仍走 F11；不把旧格式默认为双长弓。Q2 的 schema、资格 policy 和旧 checksum 含义不变，F13 本身的版本及完整布局 checksum 将新准入绑定到资格证明。未开放第三张长弓、升级长弓、长弓跨 D/H/T/F 分布或任意技能历史。

角色资源仍是独立 C3 层，本轮正式场地来源限定 False、未满充。不将 D/H/T/F 资格成功换称角色能力卡状态证明。总体 `fullPlayerExactRestorationProven` 继续为 false。

## 两个同定义副本的身份与恢复顺序

两张卡按保存的 FIELD 槽位确定 pairOrdinal 0/1；实际重建继续保留既有 HAND 优先暂存顺序，因此完整出牌见证可以按0→1或1→0执行，不能用“第一张同名卡”匹配替代精确位置与身份。

任何数量抑制前，先记录两份完整 initial-pair-bound。各自绑定计划槽位、卡牌／效果 GUID、owner、对象与共享控制块、效果数组及容量、完整 flags 原始存储、世界／引擎和 weak identity。两个副本的可变存储范围必须跨角色互不重叠，包括原生对象、24字节共享控制块、效果数组、效果对象、flags稀疏存储容量、条目和 allocation words。相同 flags 值、共同世界／引擎不构成别名；相同可变地址或交叉范围则拒绝。

每张卡独立完成四段见证：抑制前、抑制后、数量恢复前、恢复后。数量严格为1/0/0/1，位置严格为HAND/HAND/FIELD/FIELD；除数量及位置外均须保持该副本初始绑定。两组不可交错，每组完成并解除抑制、原生队列离散检查为空后，才允许继续下一张或全局资格读取。任何 count=0 期间不得执行全玩家 Q2 读取，只能读取已经绑定的单卡原始描述。最终 F1 将两份见证分别绑定到各自实际卡牌及效果。

独立审计最后加强了 queued-play 绑定：每组抑制窗口内必须恰有一次出牌队列事件，其完整 reason 中的 FIELD row/index 必须匹配保存槽位，actor 必须匹配该副本最终 F1 的实际对象短名。错误槽位、错误actor、重复或截断记录均不能通过；不能仅凭“窗口内出现某次出牌”认定当前副本已正确出牌。

全部布局、数值、数量恢复与队列条件完成后，才进入一次既有 ONCE batch。按全局 Q2 的确定位置逐目标回放，保存向量与调用数为：

| 按保存槽位的 used 向量 | true 调用数 | 目标要求 |
| --- | --- | --- |
| [0,0] | 0 | 两个新生效果均保持0 |
| [1,0] | 1 | 只修改第一个保存槽位对应效果 |
| [0,1] | 1 | 只修改第二个保存槽位对应效果 |
| [1,1] | 2 | 两个不同效果各一次 |

每次调用前后仍核对完整玩家资格及既有数值／队列快照，允许的变化只有当前目标 used0→1。没有 setter(false)、直接写 flags、直接写角色许可或重新创建效果。见证、身份、日志、队列或回放失败永久终止本次资格恢复，沿用一次语义回退，不重试已调用目标；解除抑制也必须重新证明原身份，不能强写陈旧数量。

## 验收口径与交接边界

正例必须原25项 required 全为 true，同时保留完整28项 checks 和 differences；24/25不能称完整正例。独立审计保留原比较而不在此重新计算，冻结复验须重跑原比较器。负例保留实际 false 项，语义重开成功不等于玩家精确恢复成功。来源与恢复的 DLL、PID分别绑定，允许显式不同构建或新进程，不能假设同一进程。

中间身份、抑制与队列记录属于运行时断言，最终 native F1 是独立端点观测；二者不等于完整连续队列观测或 UI 注册证明。普通点击对照可证明同一目标效果在端点的 used0→1，或已用目标保持1，并核对另一副本端点资格不变；不能据此宣称点击全过程没有 accepted dispatch、没有短暂队列活动或完整 UI 历史一致。

正常发动后 turnActive=False／UI COMPLETE 的历史状态仍未开放。本阶段使用符合 activeTrue／默认数值的自然来源，不通过忽略 UI 差异扩大准入。敌人重建、重编程、角色能力卡生命周期、升级或动态效果、无限多副本、任意跨区组合、连续历史和完整战局精确恢复均不在本阶段范围。实机部分失败注入未经执行时，不作已验证声明。
